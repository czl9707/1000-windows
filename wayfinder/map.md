## Destination

An Astro MDX site in this repo that documents the construction of an infinite hand-drawn window wall as it is built — each chapter quoting the real code behind it and recording the chain of thought — with an embedded demo: a dependency-free TypeScript canvas engine showing an endless wall of windows in every direction. Meta-seed is random per page load; window identity = hash(meta-seed, world-grid coordinates); every window is a seeded tenant with per-window light genes, drawn with the boiling-line pen, idle motion, and pointer reaction.

## Notes

- Methodology source: the reference project ("all my friends are made of javascript"), full docs saved locally at `~/temp-project/site/en-*.txt` (index, blatt, rng, kopfform, merkmale, haar, zonen, raum, stift, druck, wolke, schichten, animation, fallen). The digested form lives in this repo on branch `research/reference-digest` at `docs/reference-digest.md` — read with `git show research/reference-digest:docs/reference-digest.md`.
- Adopted discipline: the engine has zero runtime dependencies; RNG, geometry, pen, and springs are hand-rolled; three-layer split — DNA (who lives there) / Motion (what is happening now) / Style (how it looks); the DNA random-number order is append-only, fields appended never inserted. The draw pipeline (ticket 010): *geometry emits marks; motion places them; style dresses them; the pen draws them* — marks carry 3D points and a numeric depth sort key, motion projects weak-perspective, the pen stays 2D. The palette is a role-resolving function built fresh each frame from the theme's two colours.
- Repo layout: engine = vanilla TS modules — `src/core/` (randomness, scene, window-shell), `src/pen/`, `src/motion/`, `src/styling/`; each chapter folder under `src/content/chapters/NN-<name>/` holds its MDX plus its demo painter, which self-registers into the shared demo runtime (`src/components/mount.ts`); docs site = Astro + MDX + CSS modules + Radix. Routes: `/` home tracking progress (full demo lives here later), `/docs/<name>` per chapter. Chapters are working documents: a chapter exists as a stub the moment its decisions start, and each closed milestone fills its chapter in. Header stays title (logo later) + theme switch; chapter navigation moves to a left sidebar later.
- Execution rides on this map (user decision): prototype/task tickets produce code merged to `main` as milestones land; each closed milestone ships its MDX chapter. Research and grilling tickets stay decision-only.
- Comments and docs in English.

## Decisions so far

- [How the reference actually builds it — chapter digest](tickets/001-reference-digest.md): deterministic via seed-hash + append-only draw order + named warp traces cached per pen; ~3 ms/frame for 9 heads in the reference (see the addendum — the wall redraws every frame instead of pre-rendering).
- [Determinism architecture — meta-seed, window seeds, traced randomness](tickets/002-determinism-architecture.md): `windowSeed(metaSeed, col, row)` is the only place grid coordinates exist; trace names are bare ids, the pen mixes the window seed into every warp and rolls the beat offset from it; one DNA stream per window plus `fork(seed, label)` for future motion; per-window Pen dropped on viewport exit; every frame redraws every visible window.
- [Astro docs scaffold — MDX chapters hosting the demo](tickets/008-astro-docs-scaffold.md): Astro 7 static site with portfolio styling (Geist/Red Hat Mono, token sheet, fixed header); chapters are a typed collection with draft/landed status; demo mounts via `mountAll()` from vanilla-TS `src/demo/`, DPR-aware loop; Radix island proven.
- [The pen on facade shapes — first hand-drawn window frame](tickets/004-pen-prototype.md): the reference's pen constants survive straight window lines as-is; the pressure curve is the one deliberate divergence (thick ends, spitz 0.6); shipped as the landed chapter `the-pen`, engine code in `src/core/` (randomness, pen, window-shell).
- [Tenant DNA schema — what genes define a window](tickets/003-tenant-dna-schema.md): no up-front gene list; the seed expands in the fixed nesting window → curtain → insider, one DNA stream per window drawn in that order; shell variance lives in the archetypes ticket, not in DNA; new genes append at the end of their layer's stream, never inserted, so existing tenants never re-randomize.
- [One seeded window, alive — DNA to full scene](tickets/005-one-seeded-window.md): skipped by user decision — no standalone one-window prototype; tenant distinctness is judged when the insider/DNA milestone lands as a real chapter.
- [Window shell archetypes — frame variants](tickets/009-window-shell-archetypes.md): every window one wide-rectangle ratio (1.6 × 1.0); sash 4 / casement 3 / picture 2 with named pane layouts, open state (closed 4 / open 2 / half-open 1, operable archetypes only); panes washed in ink at 0.05 alpha, everything else line-only (revised after landing, see the ticket addendum); shell rolls on `fork(seed, 'shell')` in order archetype → layout → open → measured; catalogue freely editable across versions, stream purity the only invariant.
- [Shell add-ons and the layer pipeline](tickets/010-shell-addons-and-layer-pipeline.md): frame variance (head kinds, face width) stays in the shell; awning/shutters/window-box become add-ons with none-dominant rolls; the scene adopts the mark pipeline — core emits 3D marks, motion projects (`s = F/(F−z)`, F = 4.2), styling dresses, the pen draws in 2D unchanged; marks stable-sort by a numeric depth key, depth lives on points; folders split `src/core` / `src/pen` / `src/motion` / `src/styling`.
- [Cursor parallax — the wall shifts with the gaze](tickets/011-cursor-parallax.md): the eye sits at the screen's centre, never the pointer; each point lands at `p·s + eye·(s − 1)` — wall plane pinned, nearer layers drift by depth; FOCAL now 30, magnification under 4% at the deepest mark; swung casement leaves and shutters carry real depth off the wall; the demo loop resolves the eye per frame through an injectable resolver (pointer stand-in for demos, canvas position for the home wall); landed as chapter `05-motion`.
- [Wall and camera — infinite pan](tickets/006-wall-and-camera.md): every grid cell holds a window at pitch 3 × 2; scale adapts to the viewport (≥ 5 × 3 windows visible, ≤ 30 at the extreme); the settled wall texture — paper stipple under ragged illustrative brick patches — ports from the prototype; drag pans with inertia, eye stays at screen centre; full redraw every frame with no trace cache — pens live and die with viewport entry/exit; the wall touches windows only through `drawWindow`, and the home page never touches the engine; the home page is the wall under the header, which gains a docs button (to a new minimal `/docs` index) and a shuffle button (in-place meta-seed re-roll, camera kept, no URL state).
- [Build the home wall](tickets/012-build-home-wall.md): landed on `home-wall` (dd89181) through TDD at four seams (`wallUnits`, `visibleCells`, `planPens`, `glide`) and three review rounds; chapter `06-the-wall` shipped, home page is the wall, `/docs` index live, prototype route on `prototype/wall-texture`; tsc/tests/build green — live-browser feel pending the human's check.
- [Pointer attention — tenants notice the gaze](tickets/007-pointer-attention.md): closed by user decision — the pointer's role ends at the eye offset driving the parallax; no per-tenant reaction layer exists in the engine, and the reaction vocabulary (curtain twitch, lamp dims, silhouette at the glass) waits with the idle-motion vocabulary.
- [Curtains — fabric on the pane](tickets/014-curtain.md): the curtain stream opens on discrete coverage levels (`0 / 0.3 / 0.6 / 1`, weights `4 / 4 / 1 / 1`) — the zero level is the bare window and ends the stream; four home kinds — panels 4 / drapes 3 / venetian 2 / roman 2; the drawn coverage is the level clamped by the kind's zone ceiling; cloth fills resolve by construction role (`fabric` / `shade` / `blind`) with texture-weight ink line work and fold-band mottling, hung inside the opening behind the glass wash, one construction at every size; the dense line work obeys the hand rule — some lines omitted outright, a kept line drawn over only part of its run, the fill carrying the texture — and the hanging cloth hangs on verticals alone (no line across the top); light and its cloth interaction stay with [Per-window colour roles and light](tickets/017-light.md). Build plan: [Land the curtain layer](tickets/022-land-curtain-layer.md).

## Not yet specified

- Accessories hanging off the shell: vines, cables, decals — the light end of the attached clutter; the masses landed as add-ons in ticket 010, these wait until the wall exists.
- Global day/night knob: one uniform time-of-day multiplier over the whole wall. Its boundary against the page theme and the per-window light genes is part of [Light](tickets/017-light.md).
- The press layer beyond the landed stipple: ink bleed, misregistration — the reference's print-look chapter, remainder not yet mapped to a wall.
- Pitfalls: which of the reference's recorded traps transfer to windows (short strokes, boiling flicker, lockstep twitching).
- Narrative depth: names/doorbells, story vocabulary per tenant, how much written text (if any) lives in the demo.
- Shareable seed state: meta-seed in the URL (the shuffle button re-rolls in place; the URL stays untouched).
- Zoom behavior on the infinite canvas.
- Content page structure: left sidebar navigation taking over chapter navigation (the minimal `/docs` index now exists; per-page chapter nav, draft/landed states); header stays title + buttons.
